##Descripción de la aplicación
Una aplicación de administración de e-commerce para venta de plantas e insumos de jardinería, para el rol del comerciante/administrador. Gestión de stock y ventas.

##Stack tecnológico
Deploy: Laravel
Base de datos: Neon db con Postgres 18.3.2
Lenguajes: PHP 8.4.19
